# 📊 Talleres de Inteligencia Artificial - Análisis Estadístico Descriptivo

Repositorio que contiene el desarrollo de talleres correspondientes a la asignatura **Inteligencia Artificial** del programa de **Ingeniería de Sistemas** de la **Universidad del Pacífico**. Los ejercicios están enfocados en la aplicación de técnicas de estadística descriptiva y análisis de datos utilizando herramientas computacionales.

## 📌 Descripción

En este repositorio se presentan diferentes talleres desarrollados con el propósito de aplicar conceptos de análisis estadístico descriptivo, organización de datos y visualización de información. A través de tablas de frecuencia y representaciones gráficas, se busca transformar conjuntos de datos en información útil para su interpretación y análisis.

## 🎯 Objetivos

* Identificar las características principales de un conjunto de datos.
* Construir tablas de distribución de frecuencias.
* Aplicar técnicas de estadística descriptiva.
* Elaborar representaciones gráficas para el análisis de datos.
* Interpretar los resultados obtenidos a partir de evidencia cuantitativa.

## 📈 Temas abordados

* Regla de Sturges.
* Frecuencia absoluta y relativa.

* Histogramas.

* Ojivas o curvas acumuladas.

## 🚀 Objetivo académico

El propósito de estos talleres es fortalecer las competencias relacionadas con el análisis de datos y la interpretación de información mediante técnicas estadísticas, contribuyendo al desarrollo de habilidades fundamentales para el área de Inteligencia Artificial y Ciencia de Datos.
